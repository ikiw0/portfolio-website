ReviewIN AI

A machine learning web application for detecting potentially fake e-commerce reviews by classifying reviews as HUMAN or BOT. The system uses Regex preprocessing, TF-IDF, and Logistic Regression with automated Amazon review extraction.

WHAT I DID

  • Built a review processing pipeline using Regex for review segmentation and metadata cleaning.
  • Applied TF-IDF and Logistic Regression to classify reviews as HUMAN or BOT.
  • Integrated Selenium for automated Amazon review extraction.
  • Developed a fraud score and dashboard to visualize review classification results.
  • Added explainable AI features to identify keywords influencing BOT predictions.
